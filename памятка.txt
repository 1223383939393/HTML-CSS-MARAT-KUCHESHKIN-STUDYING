Текст и шрифты:

color — цвет самих букв (пример: #ffffff, red).

font-size — размер шрифта (в пикселях, например 18px).

font-weight — толщина текста (bold — жирный, normal — обычный).

text-align — выравнивание текста внутри блока (center, left, right).

text-decoration — оформление текста (например, none убирает дефолтное нижнее подчеркивание у ссылок <a>).


Коробка и отступы (Box Model):

width / height — ширина и высота элемента.

padding — внутренний отступ (дистанция от текста до рамки самой коробки).

margin — внешний отступ (дистанция от этой коробки до соседних элементов, чтобы они не слипались).

border — рамка вокруг элемента. Задается в три шага: толщина, стиль, цвет (пример: 1px solid black).

border-radius — скругление углов.


Фон и визуал:

background-color — цвет заливки фона коробки.

box-shadow — тень от элемента.

opacity — прозрачность всего элемента целиком (от 0 — невидимка, до 1 — полностью плотный).

cursor — вид мышки при наведении (pointer — рука с пальцем для клика).

Сетки (Grid):
display: grid; — включает режим невидимой таблицы для блока.

grid-template-columns — нарезает колонки (значение 2fr 1fr означает, что левая колонка заберет 2 доли свободного места, а правая — 1 долю).

align-items — управляет выравниванием элементов по вертикали внутри ячеек Grid (или внутри Flexbox). Значение start прижимает их к верхнему краю, center — по центру, end — к нижнему.

Адаптив:

@media (max-width: 768px) { ... } — контейнер для стилей, которые заработают только на экранах уже 768 пикселей (стандартный телефон/планшет). Всё, что написано внутри, перекроет обычный CSS.

max-width: 100%; — это золотое правило для картинок. Оно говорит: "картинка, ты можешь быть любого размера, но никогда не смей становиться шире своей родительской коробки". Если экран сужается, картинка сжимается вместе с ним.

Раздел: Флексбокс (Flex)

display: flex; — включает гибкую коробку (по дефолту ставит всё в ряд).

flex-direction — направление элементов (row — в ряд, column — в колонку).

justify-content — выравнивание вдоль главной оси (например, center, space-around).

align-items — выравнивание поперек оси (например, center для центровки по вертикали).

Раздел: Адаптив картинок

max-width: 100%; height: auto; — стандартный набор, чтобы картинка никогда не ломала мобильный экран и сохраняла пропорции.

Анимации и эффекты (Свистелки):

:hover — срабатывает при наведении мыши.

:focus — срабатывает при клике внутрь поля ввода.

transition — задает плавность любых изменений (например, 0.3s).

transform — трансформация элемента. translateY(-10px) двигает по вертикали вверх. scale(1.05) - зум

@keyframes имя_анимации { ... } — создает сценарий анимации от 0% (старт) до 100% (финал).

animation: имя время стиль; — запускает созданную анимацию на конкретном элементе.

opacity — это плотность (непрозрачность) элемента. Значение 0 делает блок абсолютно невидимым (как призрак). Значение 1 делает его на 100% плотным и видимым. Всё, что посередине (например, 0.5), делает блок полупрозрачным.

transform: translateY(30px) — когда мы делали эффект парения для формы регистрации, мы использовали отрицательное значение (-10px), чтобы потянуть ее вверх. Здесь значение положительное, значит, на старте (в кадре 0%) мы искусственно опускаем весь твой сайт на 30 пикселей вниз.

transform: translateY(0) — это команда "вернись на свою исходную нулевую координату", туда, где блок и должен стоять по верстке.
